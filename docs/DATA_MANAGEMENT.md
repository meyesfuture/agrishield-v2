# Data Management & Provenance

## Folder contracts

- `data/inbox/gemini_phase5/phase5_acquisition/`: original Phase 5 package contents; never edit in place.
- `data/inbox/other_reports/`: additional audit reports and extracts awaiting review.
- `data/raw/`: copies/snapshots ingested by the app's own pipeline, immutable after write.
- `data/processed/`: normalized tables generated by versioned scripts.
- `data/derived/`: chart features, aggregates and alert candidates with explicit transformations.
- `data/synthetic/`: generated/demo-only records; must never be merged with observed data without an explicit type label.
- `data/manifests/`: catalog, checksums, coverage, source terms, schema version and run metadata.

## Required metadata for every import

`dataset_id`, `source_id`, original file name, source URL, retrieval timestamp (UTC), source-reported as-of date, query parameters, HTTP status if applicable, schema version, file size, SHA-256, row count, columns, primary key or duplicate policy, geography/crop coverage, date range, units, license/terms, known limitations, and import status.

## Required quality rules

1. Blank/unreported values remain null. Explicit source zero stays zero.
2. Preserve original value/unit and normalized value/unit when converting.
3. Record conversion factor, rationale, formula and source for any unit conversion.
4. Keep wheat, paddy, raw rice, parboiled rice and rice-equivalent amounts distinct.
5. Keep production, mandi arrivals, procurement, movement, stock, capacity and milling output distinct.
6. Never add arrivals and procurement as independent supply unless overlap is explicitly resolved at record/transaction level.
7. Do not sum cumulative series across dates.
8. Do not treat one-date snapshots as time series.
9. District/mandi joins require reviewed stable identifiers and boundary vintage. Keep raw name and mapping confidence.
10. Unknown/missing district mappings stay unknown; no fuzzy match without a stored, reviewable crosswalk.
11. Validate chronological order, duplicate keys, impossible values, missing dates and unit drift.
12. All generated tables retain source lineage to input files and transformation version.

## Minimum data pipeline outputs

- `data/manifests/dataset_catalog.csv` (or JSON equivalent)
- `data/manifests/import_run_<timestamp>.json`
- `data/processed/quality_report_<timestamp>.json`
- `data/processed/coverage_matrix.csv`
- a machine-readable blocked-source report
- a human-readable import summary

## Synthetic data rules

Synthetic values may only be used to test UI states or demonstrate a hypothetical anomaly scenario. Write them to `data/synthetic/`, mark every affected record `data_status=synthetic`, put a visible synthetic banner in all related views, and do not include synthetic rows in real dataset totals, statistics or model evaluation.
