# Additional Reports — What to Add

The essential audit reports supplied so far are already copied into `docs/research/source_reports/`. You do **not** need to upload them again if they appear there.

Add any newer or missing versions here, especially:

- `FINAL_ACCEPTANCE_TESTS.md` or a full test log;
- `NEXT_ACTIONS.md` and `HOARDING_DETECTION_FEASIBILITY.md` if they contain decisions not already captured;
- newer API request/response logs or official download manifests;
- signed/offline data access approval details with secrets removed;
- later acquisition reports that supersede Phase 5.

Do not add credentials, `.env` files, session cookies, private tokens, or unredacted personal/warehouse data. Name reports with date/phase when multiple versions exist. The agent must identify the latest report by timestamp/content and preserve older ones for history.
