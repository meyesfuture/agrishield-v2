# Punjab GrainWatch

**Purpose:** A Punjab-focused agricultural intelligence platform for exploring grain-related evidence, data coverage, public stocks, crop production/yields, market prices, weather, and carefully qualified statistical anomalies.

> **Scope boundary:** The current evidence supports a source-separated descriptive dashboard and data-quality/anomaly-screening prototype. It does **not** support a claim that the system detects private grain hoarding. Do not create or display a probability of hoarding, accuse a market/business/person, or treat missing observations as zero.

## Recommended default stack

Use the existing stack if the repository already contains one. Otherwise use **Astro + React + TypeScript** for the frontend/interactive dashboard, **FastAPI + Python** for ingestion and data APIs, and **PostgreSQL** for structured data. Add PostGIS only if its spatial queries materially help. Use Three.js/React Three Fiber for the 3D hero only if the performance and bundle budget are acceptable. Pin actual package versions based on the current environment; do not invent version numbers.

## Workspace map

- `docs/` — canonical product, architecture, data, API, UX, security, testing, roadmap and research docs.
- `prompts/` — phase-by-phase implementation prompts.
- `data/inbox/gemini_phase5/` — extracted Phase 5 evidence, scripts, logs, raw and processed datasets.
- `data/inbox/other_reports/` — later reports or supporting research you add.
- `data/raw/` — immutable raw data managed by the implemented ingestion pipeline.
- `data/processed/` — validated/normalized tables generated by reproducible processing.
- `data/derived/` — explicit calculated features and chart-ready views with lineage.
- `data/manifests/` — data registry, checksums, query parameters, retrieval timestamps and schema versions.
- `logs/`, `scripts/`, `tests/` — operational traces, tooling and automated checks.

## Current state

The Phase 5 report documents 3,892 APMC arrival records for 62 produce commodities across 8 districts from October 1–21, 2026. It reports **zero daily grain arrival records** in that panel. The AGMARKNET weekly feed contains paddy prices but no arrival quantities; its core arrival route requires CAPTCHA. CEDA requires an authorized bearer token. National stock totals are not Punjab-specific inventory. The source files are bundled so the agent can reproduce these findings from rows, not only repeat the report.
