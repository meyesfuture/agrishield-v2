# Incoming Files

Drop new supporting files into `other_reports/` and data archives into a clearly named subfolder under `inbox/`. Do not overwrite the Gemini Phase 5 source drop. Ask the coding agent to:

1. list files and identify formats;
2. read reports before assuming any claims;
3. verify ZIP integrity and manifests;
4. hash files and register paths/source/date;
5. compare report numbers to actual data;
6. record conflicts rather than silently choosing one report;
7. keep originals unchanged and produce new normalized outputs elsewhere.
